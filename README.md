# Dental-Match
Es una plataforma web que conecta estudiantes de odontología con pacientes, permitiendo que los pacientes encuentren atención y que los estudiantes consigan práctica clínica real.

## Documentación
- [TRASPASO.md](TRASPASO.md): cómo poner el proyecto en marcha con cuentas propias, variables de entorno y cómo desvincularse al entregarlo.
- `npm test`: corre los tests (no tocan ninguna base real).
- `npm run calidad`: mide la calidad del código según una rúbrica.
- `npm run verificar --prefix backend -- --api=<url> --front=<url>`: comprueba que un despliegue quedó bien armado.
